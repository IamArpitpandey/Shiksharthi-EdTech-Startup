## 📖 About the Project

Shiksharthi is an AI-powered educational platform designed to make learning smarter, easier, and more accessible for students across India.

Our mission is to transform traditional learning through artificial intelligence, personalized study experiences, interactive assessments, and digital educational resources.

Shiksharthi brings learning, revision, practice, and performance tracking together in one platform.

## ✨ Key Features

### 🤖 AI-Powered Study Tools
- AI-generated lecture summaries.
- AI-powered doubt-solving assistant.
- Automatic lecture transcripts.
- Smart revision materials.

### 📚 Learning Resources
- Recorded and live video lectures.
- Digital notes and PDF resources.
- Previous Year Questions (PYQs).
- Smart library search.

### 🧠 Smart Practice
- Adaptive quizzes.
- Personalized flashcards.
- Topic-wise practice.
- Performance-based learning recommendations.

### 📊 Student Dashboard
- Track learning progress.
- Identify strengths and weaknesses.
- Monitor academic performance.
- Get personalized study recommendations.
